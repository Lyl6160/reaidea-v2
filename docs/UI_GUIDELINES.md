# reAIdea UI Guidelines

Version: 0.3

---

# Design Philosophy

The interface should feel intelligent.

Not futuristic.

Not cluttered.

Professional.

Calm.

Focused.

---

# Visual Identity

Dark Theme

Deep navy backgrounds

Bright cyan highlights

Soft white typography

Rounded corners

Subtle glow

Smooth animations

---

# User Experience

The interface should always answer:

Where am I?

What do I need to do next?

What has the Project learned?

---

# Animation

Animations should have purpose.

Never animate for decoration.

Good animation explains.

Good animation guides.

Good animation rewards.

---

# Dashboard

The Dashboard is Mission Control.

It should always display:

Project Health

Knowledge Level

Confidence

Recommendations

Recent Learning

Upcoming Tasks

---

# Interview

The Interview should feel like a conversation.

Never a survey.

Every completed answer should visibly increase Project intelligence.

---

# Knowledge

Knowledge should appear alive.

Growing.

Connecting.

Learning.

---

# Guiding Principle

Beautiful software disappears.

The Project remains the focus.
