# reAIdea Foundations

## Purpose

This folder contains the founding philosophy, identity and long-term intent of reAIdea.

These documents explain why the company exists before explaining how the product is engineered.

They should be read before the blueprints.

---

## What Belongs Here

- Founder's Letter
- Manifesto
- Vision
- Company Context
- Engineering Principles
- Founding commitments

---

## What Does Not Belong Here

- Product blueprints
- Technical implementation
- Software code
- Engineering investigations
- Daily notes
- Research material

---

## Reading Order

1. FOUNDERS_LETTER.md
2. VISION.md
3. MANIFESTO.md
4. COMPANY_CONTEXT.md
5. ENGINEERING_PRINCIPLES.md

---

## Engineering Principle

The foundations explain why reAIdea exists.

Blueprints explain how it is engineered.

Implementation explains how it is built.

If the implementation conflicts with the foundations, the implementation must change.
