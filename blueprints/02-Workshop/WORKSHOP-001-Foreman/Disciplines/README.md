# DISCIPLINE-001 – Discovery

## Purpose

Discovery is the first engineering discipline inside the Workshop.

Its responsibility is to transform observations into clearly defined engineering problems.

Discovery never engineers solutions.

Discovery reduces uncertainty until the Project is ready for the next engineering discipline.

---

## Inputs

- Project
- Original Observation
- Current Engineering State

---

## Outputs

- Engineering Problem Statement
- Updated Engineering State
- Recommended Next Discipline

---

## Success

The Project is clearer than when it entered Discovery.
