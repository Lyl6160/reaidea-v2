## Architecture and provenance

The approved SVG uses `viewBox="0 0 512 512"`, a transparent background and independently, deterministically authored vector geometry. It contains no embedded raster or data URL, external resource, script, animation or `foreignObject`. The clean founder-supplied screenshot was visual-reference evidence only and is not authority, source material or a runtime asset.

The responsive review HTML uses repository-relative references to the protected CSS and SVG named above. This link-only remediation changed no structure, wording, accessibility attribute, layout or reviewed size.

Source recovery previously established that no compliant independent pre-flattening source existed for any of the three pathway icons. V1 and V2 remain founder-rejected temporary evidence and are not copied into this authority. They cannot become source material, fallback or runtime authority.

The SVG is decorative. The pathway title and description must remain live semantic HTML, and runtime integration must prevent duplicate screen-reader announcements, for example by hiding the decorative SVG from the accessibility tree while preserving the live text.
