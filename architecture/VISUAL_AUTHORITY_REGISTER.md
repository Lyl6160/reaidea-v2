## Live visual identity and truth rules

- The complete reAIdea logo is a live accessible emblem and wordmark treatment; navigation and controls are never baked into a logo image.
- REV means Realize · Engineer · Validation. Its gold-capital rule applies to the REV expansion, not the reAIdea wordmark.
- Runtime text, controls, status, emblems, electrical treatment, candidate outputs and 3D remain responsive live layers.
- Flattened visual authorities may contain illustrative states. Percentages, checkmarks, completion, evidence, Concept number or 3D claims are never copied without matching runtime truth.
- Home understanding/readiness never displays a percentage or claims confidence, feasibility or probability of success.
- Workshop progress may display a percentage only when calculated from real canonical Project state. Static, invented or unsupported values are prohibited.
- STOP/GO is historical sample content only and cannot become product or visual authority.
- A visual asset approval does not authorize code changes. Every use still requires a bounded Build Contract and browser acceptance.
