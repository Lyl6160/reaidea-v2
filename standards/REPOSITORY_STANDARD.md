# Repository Standard

Version 1.0

Purpose

This document defines the permanent organisational structure of the reAIdea repository.

The repository is an engineering asset.

It should remain organised, understandable and scalable throughout the life of the company.

────────────────────────────────────────────────────────

# Engineering Principle

Every document must have:

• A clear purpose.

• A logical location.

• A defined owner.

• A reason to exist.

If a document does not satisfy these principles, it should be reviewed before being added.
